# aes v1

A lightweight Go package that provides simple AES (Advanced Encryption Standard) encryption and decryption utilities. This package offers convenient methods to encrypt and decrypt data using various input and output formats.

## Installation

```bash
go get -u github.com/metadiv-io/aes
```
